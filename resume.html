First designer at the company. Designed the consumer app, the owner web app, the white label system all of them wear, and the lifecycle messaging between visits. Moved into product management in 2025, setting scope and sequence with the founder.

  • Designed iVin, the consumer vehicle app, from nothing: the first screen, service history, booking, and the notification model underneath.
  • Designed the owner web app, the dealership facing surface on the same vehicle record, and the theming that lets each dealership wear it.
  • Built and maintained the white label design system. Separated brand accent from status meaning at the token level, so adding a dealership is a configuration job and never a design one.
  • Designed the lifecycle engine: one timeline per vehicle rather than campaigns, triggered email and SMS. Worked directly in MJML, SendGrid and deliverability, because a message that does not arrive correctly is a design that does not exist.
  • Designed the referral program inside those messages, with copy that stays true across eight different cases.
  • Shipped agentic AI workflows and MCP integrations as product work, including an automated verification tool for milestone communications: headless browser form fill, document lookup, and a scheduled run that returns a pass or fail per milestone instead of a person reading inboxes.
